# Socio-Economic Segmentation of US Counties

## Objective
To segment US counties into socio-economic groups using clustering techniques.

## Dataset
ACS 2015 County Data (Kaggle)

## Tools Used
- Python
- Pandas, NumPy
- Scikit-learn
- Seaborn, Matplotlib

## Methodology
1. Data Cleaning
2. Feature Selection
3. Data Scaling
4. KMeans Clustering
5. Cluster Analysis

## Results
Identified 4 major socio-economic clusters:
- Developed
- Underdeveloped
- Middle-Class
- Urban Dense

## Conclusion
The model provides actionable insights for regional economic analysis.
